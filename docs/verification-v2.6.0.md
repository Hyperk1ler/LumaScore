# LumaScore 2.6.0 验证

环境：Apple M5、macOS 27。Release 构建包含 arm64 与 x86_64；实机执行覆盖 arm64。

- 原生构建、应用自检通过，项目声明使用 `.lumascore` 与独立文档标识。
- 项目保存后恢复轨道删除、排序、逐轨流速、位置和真实秒数延迟。其他文档格式、缺少格式标识、错误扩展名及未知版本均被拒绝。
- 六套原生预设全部验证，个人预设与配色保存、修改、删除通过。切换内置样式保留场景、模板、媒体时间、曲目信息、节拍器与和弦来源。
- 和弦验证通过：22 个明确音乐案例、12 个调的移调、4,095 组八度叠加、事件边界、多轨选择、反向寻址及重叠同音。
- 音频 FFT/RMS、快捷键、轨道编辑、GPU 通道、三种音频模板、竖屏视频及 WebM 导出回归通过。
- 工作区四种展开／收起状态通过；实际测试窗口包含 10 个原生工具栏项、系统红绿灯及统一标题栏。
- MIDI＋音频延后播放的两次验证均为 0 ms 画面时钟停滞／倒退；音频与画面最大偏差约 0.22 ms。暂停、寻址和重复循环通过。

公开源码、资源和文档检查覆盖文本与二进制内容。发布应用剥离本机调试路径后重新签名；第三方组件的许可证和来源记录完整保留。

离屏渲染与播放时钟验证不等同于持续 GUI 呈现帧率测量。测试程序和日志保留在本机 `native/build/tests/`，不进入发布源码。
