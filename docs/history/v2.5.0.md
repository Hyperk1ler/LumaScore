# LumaScore 2.5.0

顶部功能键拆为独立圆形按钮，LumaScore 名称以普通文字显示。新增清空项目按钮，清空全部 MIDI、音频、封面和背景，视觉效果恢复默认值；清空前确认，保留已保存的项目文件、原始媒体和预设。

MIDI 导入改为追加，支持分批导入和重复导入同一个文件。已有轨道、颜色、静音/独奏、手动 BPM、和弦/镜头来源及播放位置保留。首次导入仍自动读取首个 MIDI 的速度。

选择轨道后，在“场景 / Scene”的“轨道布局 / Track layout”中独立设置流速、横向位置、纵向位置和时间偏移。流速和位置只影响视觉，不改变真实 MIDI 音高或音符触发时间；正时间偏移延后该轨道，和弦、镜头反应及导出时长同步调整。

轨道卡片新增删除按钮，右键菜单也可删除或打开布局编辑。项目保存包含剩余轨道与排序，重新打开不恢复已删除轨道；删除某个文件的全部轨道后，项目不再要求该文件存在。

项目保存包含轨道编辑记录，避免重新打开后恢复错误内容。当前项目格式以使用指南为准。

回归覆盖追加与重复导入、无效导入保留当前项目、删除后重开项目、布局存储、慢流速可见音符、延后轨道的和弦/镜头/时长、清空项目后阻止旧异步结果恢复。检查原生窗口的独立按钮、轨道编辑入口、播放连续性及带音频的竖屏 MP4 导出。
