# LumaScore 2.4.0

将选定的 Pen 方案落实到原生 App：窗口采用统一的 macOS 工具栏，媒体库与检查器可分别收起。窄媒体栏保留导入、文件信息与轨道操作入口；窄检查器保留模板、节拍器、频谱高度、纹理、Z 深度、透视倾斜和 CRT 编辑，并可打开完整分类面板。

音频场景新增 Orbit、Spectral Field、Record Sleeve 三种模板。Record Sleeve 保留原左右布局与封面大小，仅垂直居中内容组。背景包含可调细网格、轨道环、刻度与颗粒；和弦排版随模板配合，全部进入视频导出。

节拍器为独立可选项，切换模板保留开关、曲目信息、字体、和弦与媒体延迟。每拍交替到达左右端点，MIDI 速度变化沿文件速度图计算；开头留白期间居中待机。仅音频时使用手动 BPM，首次开启从 120 BPM 开始，可在播放栏修改。

工作区收起状态单独保存，不改变导出画布。延后播放使用连续画面时钟及提前准备音频的方式。
