# LumaScore 2.6.0

项目使用独立的 `.lumascore` 文档格式与文档类型标识。本机设置、个人预设、配色及检查器状态使用 LumaScore 存储键，不自动迁移其他应用的数据。项目打开时验证扩展名、格式标识和版本。

内置样式重新编写为六套原生定义：Signal、Ember、Polar、Graphite、Afterglow、Raster。直接使用 Swift 设置模型，不需要外部预设 JSON 或 JavaScript。切换内置样式保留场景、模板、曲目信息、媒体时间、节拍器和和弦来源。

和弦测试使用独立编写的音乐示例、十二个调的移调检查和 4,095 组八度重叠检查。保留多轨分析、转位、扩展和弦、延后轨道与任意寻址功能。

公开源码包含原生应用、测试、设计文档、打包工具和使用说明。所有使用中的第三方编码组件保留完整许可证和来源记录。
