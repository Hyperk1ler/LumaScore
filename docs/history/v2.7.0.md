# LumaScore 2.7.0

增加 Metal 4 自适应渲染提交。在支持的系统和 GPU 上复用命令缓冲、三组命令分配器与参数表，显式维护资源驻留和渲染阶段之间的屏障。旧系统与不支持的 GPU 使用原有 Metal 通道。

有发光内容的画面继续使用 MPS 光晕；空光晕跳过发光纹理、下采样和模糊通道。改变光晕半径复用现有纹理，只更新模糊核。可能稍后出现音符或粒子的场景预热光晕资源，避免把首次分配推迟到媒体开始时。

两条队列仅在后端切换时同步，连续帧保持三帧流水线。GPU 完成回调释放帧槽，预览中的 GPU 错误会暂停播放并显示原因。

增加参考通道与自适应通道的真实像素比较、4K 与淡入淡出检查、实时编辑时的跨队列同步回归，以及可重复的交替导出基准。导出报告包含实际后端。性能收益与测量限制见[性能记录](../performance/metal4.md)。


## 发布整理

- 发布版本 2.7.0，build 11；应用安装包、自有源码包、WebMRuntime 对应源码包和 SHA-256 校验文件随同发布。
- 新增渲染回归测试、可复现基准工具及性能记录。离屏测试与完整视频导出的结论分别列出；本机完整 MP4 导出没有显著加速，不宣称整体倍速提升。
- 调度、NV12 与 PixelBufferReceiver 三组实验保留在 `native/Experiments/ExportPipeline/`，包括补丁、源码散列和取消／颜色检查。因收益和画质尚不足以支持采用，没有替换应用默认导出实现。
- 更新第三方源码下载入口；WebM 编码器二进制与依赖版本未改变，仍保留完整许可证及免费对应源码。
- 本机宣传视频、用户音频／MIDI、渲染中间文件与测试构建日志不进入源码仓库或 Release。

验证结果见[2.7.0 发布核验](../verification-v2.7.0.md)。
