# LumaScore · Pen design study

已选方向在 LumaScore 2.4.0 中落实到 SwiftUI 与 Metal 渲染器。应用窗口与视频画面分别设计，三种音频画面可在 App 中切换。

## 已选方向 · 第二轮

- UI 以 A 为基础，采用 C 的窄媒体栏。顶部工具栏提供左右两个独立的收起按钮。
- 媒体栏收起后保留音频、MIDI、封面、轨道入口，点击可访问导入、文件信息与轨道操作。
- 属性栏收起为 84 pt 的窄编辑栏：保留场景、特效、文字入口，以及纹理、Z 深度、倾斜数值、CRT 与节拍器开关。
- 分类入口打开贴边快捷面板，访问对应分类的全部参数；完成编辑后可关闭面板并继续保留侧栏收起状态。数值支持输入与拖动调节，文件与轨道名称通过面板或提示显示。
- 四张交互状态稿：两侧展开、仅左侧收起、两侧收起、收起后打开快捷面板。
- 三种频谱画面都作为模板。节拍器使用独立开关；切换模板保留这个开关的状态。BPM 数值仍单独显示。画面 1 示例开启节拍器，画面 2、3 示例关闭。
- 模板 3 按用户修正保留原左右排版、封面大小、频谱与波形位置关系，仅将左右内容组垂直居中。
- 侧栏状态属于工作区偏好；导出采用独立的 16:9 视频画布。

`previews/ui-refined.png` 为第二轮交互状态对照，`previews/sleeve-centered.png` 为模板 3 的最新稿。全部为 Pen 设计稿，程序实现随后依据此规格进行。

## 应用窗口

| 方案 | 重点 |
| --- | --- |
| A · Unified Native / 原生工作台 | 与 macOS 红绿灯同一条工具栏，清晰的媒体库、画布、属性检查器 |
| B · Instrument / 仪器面板 | 下方参数工作区，集中调节深度、透视、纹理与节拍响应 |
| C · Canvas / 沉浸画布 | 宽画布、收起的媒体栏、浮动播放控制，更适合观看与调整画面 |

## 导出画面（16:9）

| 方案 | 重点 |
| --- | --- |
| 1 · Orbit / 仪表 | 接近参考：封面周围的轨道刻度、背景细网格、频谱与波形 |
| 2 · Spectral Field / 频谱场 | 频谱占主导，紧凑标题和封面，青绿色技术视觉 |
| 3 · Record Sleeve / 片封 | 更大的封面、较安静的背景与排版，适合音乐发布 |

所有曲目、频谱、波形与分析读数均为设计占位，不能作为真实音频分析结果。封面为原创文字与渐变占位。

## 运动与时间

- BPM 旁的横条是节拍器。每拍到达左右端点，两个节拍完成一次往返；144.2 BPM 时，每拍约 416 ms。
- 音频与 MIDI 延后开始时，视频依然从零秒持续渲染。节拍器在媒体开始前保持居中，背景纹理与入场动画仍然显示。
- 节拍从媒体时间与 MIDI 速度图计算，不能用视频进度替代。暂停与拖动时对应到同一相位。
- 纹理包含细网格、主网格、同心环、刻度与轻微颗粒；与 CRT 扫描线、鱼眼镜头分别控制。实现时保持低对比，避免盖住文字与频谱。
- 字体选择仅提供本地字体；界面保留中文与英文。正式实现采用 macOS 系统字体与原生窗口控件。

## 文件

- `../../Design.pen`：可编辑设计文档，使用 Pen 打开。
- `assets/scene-texture.glsl`：设计用背景纹理。
- `assets/metronome.glsl`：设计用节拍运动示意。
- `previews/`：导出的预览，设计确定前不发布到仓库。
- `previews/ui-options.png`、`previews/scene-options.png`：三套 UI 与三套视频场景的对照图。
- `pen-drafts.layer-backup.json`：通过 Pen MCP 读取的第一轮部分图层备份（UI A、B 和画面 1、3），用于恢复历史稿。最新第二轮稿以当前 Pen 画布和本地保存的文档为准。按 `parentId` 可恢复已备份层级，资源路径以项目根目录为基准。
- `pen-layouts.js`：Pen 执行接口的初始布局生成函数，最终方案还包含画布内的细节调整。

当前 Pen 画布包含七块初稿及四块第二轮 UI 状态稿；频谱模板 3 已按最终修正保留原布局并垂直居中。请在 Pen 中按 ⌘S，将画布改动保存到 `Design.pen`。Pen MCP 当前没有保存本地 `.pen` 文档的接口。

设计文件作为可编辑参考保留；2.4.0 的原生工作区、三种音频模板、可选节拍器及背景纹理已接入 App，预览与视频导出使用同一个渲染器。
