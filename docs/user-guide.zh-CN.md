# LumaScore 使用说明

LumaScore 将 MIDI 音符与音频频谱渲染为视频。音频提供声音，MIDI 提供音符和视觉反应；应用不合成 MIDI 乐器声音。M/S 控制可见轨道，不会把一份成品音频拆分成乐器轨道。

## 开始创作

1. 导入音频、MIDI 或两者。选择 MIDI、Audio 或 Hybrid 场景。
2. 左侧轨道显示 MIDI 文件和轨道名称。右侧 Scene／Effects／Text／Export 配置画面。
3. 首次 MIDI 导入自动读取首个文件的速度；再次导入会追加轨道并保留当前 BPM 与已有轨道设置。手动 BPM 只改变 MIDI 时间。使用“原速”恢复文件速度。
4. 导入封面或背景，编辑标题、作者与曲目信息。字体只使用本机已安装字体，安装新字体后重启应用。

顶部工具栏与 macOS 红绿灯处于同一窗口区域。左右侧栏可独立收起；左侧窄栏的媒体入口可查看文件与编辑轨道，右侧窄栏可直接调整频谱高度、网格、Z 深度和倾斜，点击分类可打开完整快捷编辑面板。F 临时收起两侧，Esc 恢复工作区。

Audio 场景提供 Orbit、Spectral Field、Record Sleeve 模板。模板 3 保留左右布局与封面大小并垂直居中。网格纹理、细微颗粒和节拍器均可调；模板切换保留曲目、字体、和弦与媒体时间设置。节拍器开关独立于模板，每拍到达交替端点，两拍往返一次；有 MIDI 时跟随速度图与手动速度比例，仅音频时使用手动 BPM（首次开启为 120）。音乐开始前游标居中，暂停及寻址保持对应相位。

频谱来自 PCM FFT，波形为 RMS 汇总。仪表是 RMS dBFS／短窗口动态范围估计，不是 LUFS 测量。频谱的 Z 深度、透视倾斜和置前控制可用于混合场景。和弦来自选中的 MIDI 轨道，并接受场景的镜头、调色和 CRT 效果。

## 轨道编辑与重置

MIDI 支持分批追加；重复导入同一个文件会创建一组独立轨道。点选轨道，进入右侧“场景 / Scene”的“轨道布局 / Track layout”：流速为视觉滚动比例（0.25–4×），X/Y 为相对画布的百分比位移。它们不会改变 MIDI 音高、和弦或音符触发时刻。单独的“延后 / Time offset”以真实秒数调整该轨道的触发时间，正数延后、负数提前；和弦与镜头反应会同步，正偏移可延长视频时长。音频保持原来的播放时间。

轨道卡片的垃圾桶删除此轨道；右键可打开布局编辑或删除。删除与排序会保存在项目中，重新打开不会恢复被删除轨道；源 MIDI 文件不被修改。删除某个文件的所有轨道后，该文件从媒体列表和项目引用中移除。

顶部独立圆形按钮依次提供预设、打开项目、保存、清空项目、导出及检查器开关。清空项目需要确认，并会停止播放、清空全部媒体，将视觉效果恢复默认值。保留原始媒体、磁盘上已保存的项目和个人预设。左右侧栏收起偏好继续保留。

## 播放与对齐

“Media lead-in / 音频与 MIDI 延后”推迟媒体启动，背景、封面、标题与场景仍从时间零开始渲染。音乐开始前频谱无活动能量，MIDI 不触发活动标记／镜头／和弦。“从头预览入场”忽略导出选区。

未编辑文本时，Space 播放／暂停，Return 返回开头；左右方向键寻址五秒，上下方向键调整监听音量，R 循环，F 最大化，Esc 退出最大化，M/S 操作选中轨道。数字框 Return 确认并退出编辑，Escape 取消；编辑状态保留正常文字输入。

有留白时，音频在画面持续渲染期间提前准备。无留白或从音乐段恢复时，音频准备好后再起播，以保留媒体起点。暂停、拖动、循环或更改延迟会取消旧的音频预约。

## 项目与导出

保存项目使用 `.lumascore` 扩展名，保留设置及媒体的本机路径，不将媒体嵌入项目；移动媒体后需要恢复路径。

2.6 使用独立的 LumaScore 文档格式，包含格式标识、版本、轨道删除、排序和布局记录。其他应用的项目不能直接打开。本机设置和个人预设也采用独立存储，不自动导入其他应用的数据。

内置六套样式：Signal／信号、Ember／余烬、Polar／极地、Graphite／石墨、Afterglow／余辉、Raster／扫描。切换内置样式保留场景、模板、曲目信息、媒体时间、和弦来源和节拍器开关；个人预设可保存、修改、删除。

MP4 使用原生硬件 H.264／HEVC 与 AAC。WebM 使用内置 VP9／Opus 组件，当前只支持 Apple Silicon／macOS 27+。导出按固定帧率逐帧渲染，不是预览录屏。CRT、镜头、字体、和弦和音画淡入淡出进入导出。

应用主体目标 macOS 13+，包含 arm64/x86_64；运行验证仅覆盖 M5/macOS 27。下载版本为 ad-hoc 签名，未 Apple 公证。构建与第三方说明见根目录 README。
